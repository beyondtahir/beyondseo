# BeyondSEO README media

## The paper SEO house

The Paperworks illustrations are original BeyondSEO artwork: folded-paper helpers,
tactile website pages, ivory, charcoal and the product's burgundy accent. The existing
BeyondSEO logo is preserved. The characters inspect a page, write an answer, compare
equivalent pages and work on a connection. They explain the work visually.

The creative process used BeyondArtist Design Memory and live Pinterest research
on miniature workers, purposeful tool contact and shared tasks. Those visual principles
informed a new paper-house world. No Pinterest image, other repository's character,
franchise mascot or third-party screenshot was used as production artwork.

`paperworks/seo-house.png` is the original integrated still. The three GIFs use a
separate empty stage and an original transparent pose atlas, animated with seekable
timelines. They contain actual pose/action changes. Each loop lasts ten seconds at
10 fps. Two reframed phone versions keep the tools and their targets visible. Still
alternatives are selected by the README for reduced-motion preferences.

**These are illustrated workflows.** They are not recordings of a live audit,
simultaneous agents, account submissions, ranking gains or verified backlinks.
The 206-entry library contains opportunities, not acquired links. The native README
explains the real capabilities and their limits next to each illustration.

Editable scene sources and rendering notes are in [paperworks/source](paperworks/source/README.md).
Artwork tools are optional; BeyondSEO's engine does not need them.

`paperworks/wordmark.png` places the unchanged logo on a light backing so it remains
legible in light and dark README themes. `repository-social-preview.png` is the
prepared 1280×640 share image using the same original artwork and logo. It has not
been uploaded to GitHub settings. The [repository profile](../.github/repository-profile.json)
records the applied About description and topics; that file does not change settings automatically.

`paperworks/readme-opening.png` places the original house artwork on the left and
the unchanged logo, short headline and introduction on the right. The phone version
stacks these elements. This is precise layout and text finishing using the existing
art, not a new character design. The README keeps its description, navigation and
copyable example prompts as native text; image alternative text identifies the heading.

## Actual output and owner-authorised evidence

`report-preview.gif` replays actual BeyondSEO HTML report output using the included
fictional `examples/report-content.json`. No live client data, ranking or publication
result is shown.

`academy-search-console-20261030.jpg` is a genuine cropped Chrome Search Console capture,
made on 30 October 2026 (Asia/Karachi) with the owner's explicit permission for this README.
Property: https://academy.beyondtahir.com/. Search type: Web. Range: 28 July–27 October 2026.
Visible rounded metrics: 5.37K clicks, 222K impressions, 2.4% CTR, 6.3 average position.
Tahir states that the Academy achieved these results after using BeyondSEO. The README
identifies that owner-reported use and shows the full selected reporting window;
individual implementation dates and a matched baseline are not supplied here.
The screenshot verifies the displayed performance, not an isolated causal effect.
The live UI exposed exact totals of 5,371 clicks and 222,268 impressions. Account controls,
identifiers and query rows were excluded by a native screenshot crop; the displayed metrics
and graph were not redrawn or changed. It is a dated view of the creator's own property,
not a controlled attribution study or a promised result for users. Only this expressly
requested owner example is included; private audits and other client data remain excluded.

These repository visuals and editable sources are excluded from the portable skill upload.
Core use requires none of them.
