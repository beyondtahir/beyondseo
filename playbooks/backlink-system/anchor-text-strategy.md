# Anchor Text Strategy

This file defines safe anchor text planning for BeyondSEO backlink campaigns.

---

## 1. Anchor Types

```text
Brand anchor: BeyondTahir Academy
Naked URL: https://academy.beyondtahir.com
Partial-match: AI automation course by BeyondTahir
Topical: learn AI automation
Generic/contextual: this guide, here, full breakdown
Exact-match: AI automation course Pakistan
```

---

## 2. Choose anchors from context

Use descriptive, natural anchor text that accurately describes the linked destination. Brand and URL anchors are appropriate when identifying the source. Do not impose a universal percentage mix or manufacture exact-match quotas; the original percentage table had no cited basis. Review actual editorial context, audience usefulness and the existing link evidence.

---

## 3. Rules

```text
Never repeat exact-match anchors across many posts.
Use exact match only on strong relevant pages.
Use branded anchors for free post/library links.
Use partial-match anchors for support articles.
Use natural sentence anchors for guest posts.
```
