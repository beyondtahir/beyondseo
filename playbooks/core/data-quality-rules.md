# Data Quality Rules

Rules for judging and labeling data quality.

---

## Labels

Use Confirmed, Likely, Directional, Estimated, and Not Verified.

## Never Invent

Do not invent search volume, rankings, traffic, backlinks, reputation estimates, GBP calls, or conversions.

## Tool Data

Record source, date, metric definition and coverage for supplied authority data. A website crawl cannot calculate a complete backlink profile. Use the documented BeyondSEO rubric only for its observed sample.
